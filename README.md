# Hitesh — Portfolio

A personal portfolio website built from scratch with pure HTML & CSS. No frameworks, no libraries — just clean, hand-written code.

## 🔗 Live Preview

> Coming soon — deploy via GitHub Pages

## 📁 Structure

```
Portfolio/
├── index.html      # Full single-page layout
├── style.css       # All styles, responsive
├── fullpic.jpg     # Profile photo
└── README.md
```

## 🗂️ Sections

| Section | Description |
|---|---|
| **Hero** | Intro, profile photo, code card, education card |
| **About** | Bio, stats, info cards |
| **Skills** | Grouped by category — Languages, Frameworks, AI & Tools |
| **Projects** | Project cards with tech stack and links |
| **Contact** | GitHub, LinkedIn, Email, Instagram links |

## 🛠️ Built With

- HTML5
- CSS3 (custom properties, grid, flexbox)
- Google Fonts — Inter + Caveat
- Font Awesome icons
